1. Pembahasan Soal 1: Backend Laravel RESTful API (Nilai 15)

Backend dibangun menggunakan Laravel 12 dengan tema Sistem Manajemen Buku Perpustakaan (Library Management System). Resource yang disediakan adalah books dengan atribut id, title, author, isbn, category, published_year, stock, dan description.

A. Otentikasi Token (Laravel Sanctum)

  • POST /api/login: Menerima kredensial email & password, mengembalikan token Sanctum dengan status 200 OK. Jika salah, mengembalikan 401 Unauthorized.
  • POST /api/logout: Menghapus token pengguna aktif dengan status 200 OK.
  • GET /api/user: Mengambil data pengguna yang terotentikasi.
  • Seluruh endpoint lain dilindungi oleh middleware auth:sanctum. Permintaan tanpa token otomatis dibalas dengan 401 Unauthorized berformat JSON.

B. Status Kode HTTP RESTful Presisi

  • 201 Created: Dihasilkan saat penambahan data buku baru berhasil (POST /api/books).
  • 422 Unprocessable Content: Dihasilkan saat validasi masukan gagal (misal: field wajib kosong atau ISBN duplikat).
  • 401 Unauthorized: Dihasilkan saat token tidak disertakan atau kredensial login salah.
  • 200 OK: Dihasilkan saat pemanggilan daftar buku, detail buku, pembaruan data, dan penghapusan buku berhasil.

3 & 4. Pembahasan Soal 3 & 4: GitHub Repository & CI/CD Pipeline

Struktur repositori uts-pl-24-545740-SV-25748 memiliki dua folder utama: backend/ dan frontend/. Diterapkan strategi percabangan dengan branch main, dev, dan feature/book-crud-api-and-ui.

Workflow GitHub Actions (.github/workflows/ci.yml)

name: CI/CD Pipeline
on:
  push:
    branches: [ main, dev, 'feature/**' ]
  pull_request:
    branches: [ main, dev ]

jobs:
  test-backend:
    name: Backend Tests (Laravel)
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: shivammathur/setup-php@v2
        with: { php-version: '8.3', extensions: 'pdo, sqlite, pdo_sqlite, mbstring' }
      - run: cd backend && composer install && cp .env.example .env && php artisan test

  build-frontend:
    name: Frontend Build (Vue.js)
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with: { node-version: 22 }
      - run: cd frontend && npm ci && npm run build

  deploy:
    name: Continuous Deployment (Docker GHCR)
    needs: [test-backend, build-frontend]
    if: github.ref == 'refs/heads/main' && github.event_name == 'push'
    runs-on: ubuntu-latest
    permissions: { contents: read, packages: write }
    steps:
      - uses: actions/checkout@v4
      - uses: docker/login-action@v3
        with: { registry: ghcr.io, username: ${{ github.actor }}, password: ${{ secrets.GITHUB_TOKEN }} }
      - run: |
          docker build -t ghcr.io/${{ env.REPO_OWNER }}/uts-backend:${{ github.sha }} ./backend
          docker build -t ghcr.io/${{ env.REPO_OWNER }}/uts-frontend:${{ github.sha }} ./frontend
          docker push ghcr.io/${{ env.REPO_OWNER }}/uts-backend:${{ github.sha }}
          docker push ghcr.io/${{ env.REPO_OWNER }}/uts-frontend:${{ github.sha }}

8. Penjelasan Aliran Data (Data Flow)

  1. Pengguna di Browser berinteraksi dengan antarmuka Vue pada port 8080 (misalnya mengisi form login atau menambah buku).
  2. Axios Interceptor menyematkan header Authorization: Bearer <token> ke permintaan HTTP /api/....
  3. Nginx Reverse Proxy pada container frontend menerima request /api/... dan meneruskannya ke backend melalui jaringan internal Docker Compose pada alamat http://backend:8000/api/....
  4. Server FrankenPHP & Laravel menerima request, middleware Sanctum memvalidasi token, dan Controller memvalidasi input data.
  5. Eloquent ORM melakukan kueri SQL ke service database (database:3306) yang tersimpan permanen pada volume db_data.
  6. Backend merespons dengan JSON dan kode status HTTP yang sesuai (200, 201, 401, 422).
  7. Vue.js menerima data balasan dan memperbarui tampilan secara dinamis tanpa reload halaman.

Kendala Teknis Solusi yang Diterapkan
Respon 401 mengalihkan ke HTML Login Menambahkan $exceptions->shouldRenderJsonWhen(fn ($req) => $req->is('api/*') || $req->expectsJson()) pada bootstrap/app.php sehingga seluruh error API selalu mengembalikan JSON standar.

Race Condition Inisialisasi Database Menambahkan healthcheck berbasis mysqladmin ping pada service database dan depends_on: { database: { condition: service_healthy } } pada service backend.
Efisiensi Build Docker Memisahkan penyalinan berkas manifes dependensi (composer.json, package.json) dari kode sumber aplikasi agar Docker layer caching bekerja optimal.
